---
title: Overview
description: The authorization model behind zkMCP.
---

zkMCP treats AI behavior and authorization as separate systems. The model can remain probabilistic; the boundary around sensitive tool execution is deterministic and verifiable.

The core concepts are:

- [Access vs authority](/docs/concepts/access-vs-authority)
- [Authorization lifecycle](/docs/concepts/authorization-lifecycle)
- [Private policies](/docs/concepts/private-policies)
- [Proof receipts](/docs/concepts/proof-receipts)
- [Human approval](/docs/concepts/human-approval)
